# SIHSALUS Terminology

Monorepo for adapting Open Concept Lab's terminology service and browser to
SIHSALUS. The initial scope is SIHSALUS and its OpenMRS concept dictionary.

The upstream projects are imported with their Git histories and licenses under
`apps/`. This repository does not contain a production deployment or patient
data. Each upstream project's license remains in its own directory.

See [UPSTREAM.md](UPSTREAM.md) for source commits and update instructions.
